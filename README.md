## Selected projects

| Project | What it does | Tools |
| --- | --- | --- |
| GatePoint | Security gateway for AI agents. Enforces policy on every tool call and audits it, with no changes to agent code. It uses a three-layer trust chain: Ed25519 challenge-response, short-lived JWTs, and CA-signed certificates. Each request carries a signature over RFC 8785 canonical JSON. The policy engine supports 18 JSONPath operators, and policies can be generated by GPT-4 and validated with Zod. 2nd place at the Husky Startup Challenge. | TypeScript, Express, PostgreSQL, Prisma, React |
| [Stepglass](https://github.com/Aditya292248/stepGlass) | Self-hosted tool that records what an AI agent did and verifies what actually changed in the systems it touched. It labels each change with before-and-after evidence and checks the result against policy. Built in public under Apache-2.0. | TypeScript, Node.js |
| [openBrowser](https://github.com/Aditya292248/openBrowser) | Rust CLI that drives one persistent Chrome tab. Each command runs as a short-lived process, while a local daemon keeps the session alive. Gives structured JSON output and is tested against a real Chrome. | Rust, Chrome DevTools Protocol |
| [Neocortex](https://github.com/rusheelsharma/neocortex) | Turns a GitHub repository into a knowledge base you can query. It parses repos into AST entity graphs at about 1,000 entities per second and returns ranked, token-budgeted context to an LLM in under 500 ms. My parts were embeddings and semantic search, program-slicing compression, and the extraction commands. | TypeScript, tree-sitter, OpenAI, Voyage AI |
| [ImageDoctor](https://github.com/Aditya292248/imageDoctor) | Full-reference image quality assessment with a fine-tuned ViT-Base on KADID-10k. Uses about 70% less GPU memory through selective layer freezing and gradient accumulation. | Python, PyTorch, timm |
| [Loan Default Prediction](https://github.com/Aditya292248/loan-default-prediction) | Credit-risk model on 1.35M Lending Club loans, using only application-time features. Reaches 0.72 AUC-ROC with XGBoost, with SHAP interpretability and error analysis by loan grade. | Python, XGBoost, DuckDB, SHAP |
